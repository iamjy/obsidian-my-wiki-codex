# Second Brain Index

## Concepts

- [[on-device-ai-laptops]] - 온디바이스 AI 기능을 로컬 NPU 중심으로 처리하는 2026년형 노트북 시장 패턴.
- [[physical-ai-sensor-architecture]] - 피지컬 AI에서 센서 데이터를 지능, 엣지 연산, 제어, 안전으로 연결하는 시스템 설계 개념.
- [[physical-ai-edge-sensors]] - 환경 인식 센서 융합과 엣지 추론을 즉시 제어로 연결하는 피지컬 AI 패턴.
- [[decision-ai-agent]] - KPI 변화의 원인을 분석하고 통제 가능한 개선안을 제안하는 decision support agent 개념.
- [[semantic-mcp]] - 시멘틱 레이어를 AI Agent가 사용할 수 있는 MCP 도구 인터페이스로 노출하는 구조.
- [[edge-ai-inference-semiconductors]] - 학습에서 추론으로 이동하는 AI 수요를 온디바이스와 엣지 서버에서 처리하는 NPU·AI SoC 패턴.
- [[automotive-risc-v-shift-left-development]] - 차량용 RISC-V 전환에서 실리콘 이전에 소프트웨어 스택과 툴체인을 검증하는 프리-실리콘 개발 패턴.
- [[embedded-platform-cpu-selection]] - CPU Core, Peripherals, Firmware/RTOS/OS 실행 모델을 함께 보는 임베디드 플랫폼 CPU 선정 기준.
- [[platform-enabling-environment]] - 하드웨어, 소프트웨어, 서비스, 비즈니스에서 참여자의 생산과 이용을 쉽게 하는 공통 기반으로서의 플랫폼 개념.
- [[op-tee-trusted-execution-environment]] - Arm TrustZone 기반으로 비보안 Linux와 분리된 Trusted Application 실행 환경을 제공하는 TEE 플랫폼.
- [[nvidia-jetson-secure-boot-chain]] - BootROM, 퓨즈, PKC/SBK/OEM 키, UEFI Secure Boot로 이어지는 Jetson 부팅 신뢰 체인.
