# OP-TEE

## Source

- 원문 제목: `OP-TEE`
- 원문 URL: https://www.trustedfirmware.org/projects/op-tee/
- 수집일: 2026-05-22

## Processed Summary

OP-TEE는 Arm A-Profile 시스템에서 비보안 Linux 커널과 함께 동작하도록 설계된 Trusted Execution Environment(TEE)다. 원문은 OP-TEE가 Arm Cortex-A 계열 Core에서 TrustZone 기술을 사용하며, 일반 Linux 실행 환경의 동반 보안 실행 환경으로 배치된다는 점을 강조한다.

핵심 개념은 [[op-tee-trusted-execution-environment|OP-TEE Trusted Execution Environment]]다. OP-TEE는 보안 영역에서 Trusted Application을 실행하고, 비보안 영역의 클라이언트가 표준 API를 통해 TEE와 통신할 수 있게 한다. 이때 Trusted Application이 사용하는 내부 API는 GlobalPlatform TEE Internal Core API v1.1.x이고, 일반 실행 환경에서 TEE와 통신하는 방식은 GlobalPlatform TEE Client API v1.0을 따른다.

이 구조는 [[embedded-platform-cpu-selection|임베디드 플랫폼 CPU 선정]]에서 Core와 플랫폼 기능이 소프트웨어 구조를 결정한다는 점과 연결된다. OP-TEE는 단순한 애플리케이션 라이브러리가 아니라 TrustZone을 지원하는 Arm A-Profile 하드웨어, 비보안 Linux, Secure World 런타임, Trusted Application API가 함께 맞물려야 작동하는 보안 플랫폼이다.

## Key Claims

- OP-TEE는 Arm A-Profile 시스템에서 비보안 Linux 커널의 동반 TEE로 설계되었다.
- OP-TEE는 Arm Cortex-A Core의 TrustZone 기술을 사용한다.
- OP-TEE는 Trusted Application에 GlobalPlatform TEE Internal Core API v1.1.x를 제공한다.
- OP-TEE와 통신하는 클라이언트 측 인터페이스는 GlobalPlatform TEE Client API v1.0을 따른다.
- OP-TEE의 개발 참여와 기여는 프로젝트 문서와 메일링 리스트를 통해 이루어진다.

## Entities

- OP-TEE: Arm TrustZone 기반 Trusted Execution Environment 프로젝트.
- TEE: 보안 민감 코드와 데이터를 일반 실행 환경과 분리해 실행하는 Trusted Execution Environment.
- Linux kernel: OP-TEE와 함께 동작하는 비보안 운영체제 커널.
- Arm A-Profile: OP-TEE의 대상 시스템 범주로, Armv8-A 및 Armv7-A 시스템을 포함한다.
- TrustZone: Arm 시스템에서 보안 영역과 비보안 영역을 분리하는 하드웨어 기반 기술.
- Trusted Application: TEE 내부에서 실행되는 보안 애플리케이션.
- GlobalPlatform: TEE Internal Core API와 TEE Client API 사양을 정의하는 표준화 주체.

## Open Questions

- 원문은 짧은 프로젝트 소개이므로 OP-TEE의 부트 체인, Secure Monitor, TA 로딩, Linux 드라이버 구조는 별도 문서 ingest가 필요하다.
- 실제 제품 적용 시 어떤 키 관리, 인증, secure storage, secure boot 요구사항을 OP-TEE로 처리할 수 있는지는 추가 검증이 필요하다.
- Arm TrustZone을 지원하더라도 SoC, 펌웨어, 보드 지원 패키지, Linux 드라이버 준비 상태에 따라 통합 난이도가 달라질 수 있다.
